# Voice acting kit is ready

1. Open `HOW_TO_RECORD.md` (beginner guide, recipe cards, tick-box lists).
2. Open `VOICE_CAST.md` to see how each character should sound, and `VOICE_SCRIPT.md` for every line.
3. Record into the `voice/<character>/` folders, named like the line ID (e.g. `voice/vera/greet_1.ogg`).
4. In game, press F3 for the Voice Test menu.
