# Every voice line: record straight down this list

There are **944 lines**. Work through them in order, one character at a time.

## Two ways to record

### Easiest: the in-game Voice Studio
1. Open the project in Godot and press **F5**.
2. Press **F6** anywhere in the game.
3. Read the line on screen and press **R**. Say it, then press **R** again.
4. It saves automatically, plays your take back, and **ENTER** moves to the next line.

The studio tracks what you've recorded, so you can't lose your place. **N** jumps to the next line you haven't done.

### One folder, with your own app (Audacity and so on)
Save every file into the single folder **`voice/all/`**, using the file name in the table. Example: `voice/all/rico__greet_1.ogg`. `.ogg`, `.wav` or `.mp3` all work. The game finds them automatically.

Tick the box for each line as you go.
